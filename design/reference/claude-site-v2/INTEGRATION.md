# Design reference

This directory preserves the approved Claude Design handoff for visual and behavior audits. `Token by Token Site v2.dc.html` is the source of truth and depends on `support.js` when opened locally. Neither file is imported by the production dashboard. The React implementation is in `dashboard/src/PublicSite.tsx` and `dashboard/src/public-site.css`.

The handoff README is preserved verbatim. The SVG source is preserved here; the production copy lives at `dashboard/public/token-by-token.svg`.
